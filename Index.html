Module 09 · Delivery Roadmap · indicative

Web-first now. Native field shell next. One codebase throughout.

Phase 1 is everything in this walkthrough, delivered as a responsive web application — installable on field phones as a PWA, full desktop for the back office. Phase 2 deepens the field experience where browsers genuinely can't reach.

Phase 1 · This walkthrough

Responsive web platform — all nine modules

Desktop web for marketplace, underwriting, LMS, commissions, cockpit, communications and tenant administration. Mobile web (PWA) for field officers: installable, camera capture, geo-tagging, connectivity-aware queue-and-retry.

  • Both lending models live: BC full-lifecycle and DSA originate-and-track
  • RBI machinery built in: household assessment gate, KFS register, consent ledger, audit trail
  • Multi-lender marketplace, three-tier underwriting, commission waterfalls, FLDG tracking
Phase 2 · Native field shell

The same web app, wrapped for the last mile

A thin native shell around the identical codebase — no rewrite, no second product — unlocking the capabilities rural field work eventually demands:

  • Offline-first sync — full day's work without signal; conflict-safe sync when coverage returns
  • Aadhaar biometric devices — RD Service fingerprint/iris integration for assisted eKYC
  • Device-level security — secure storage, remote wipe, MDM enrolment for field fleets
  • Vernacular voice input — Tamil speech-to-text for field notes and PTP capture
  • App store presence for field-force credibility and managed rollouts

Sequencing indicative; Phase 2 scope confirmed against field telemetry from Phase 1 — build what usage proves necessary, not what brochures suggest.
